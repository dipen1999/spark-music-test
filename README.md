# SPARK Music Academy

An interactive, browser-based music lesson that turns a webcam into a musical instrument.

## Features

- Animated SPARK Music Academy launch logo
- Playable one-octave piano with Web Audio synthesis
- Mouse, touchscreen, and A–K keyboard controls
- On-device hand landmark recognition
- Gesture mapping: one finger = C, two fingers = D, three fingers = E
- Guided **Hot Cross Buns** lesson with visual prompts and progress
- Responsive layout for desktop and mobile

## Privacy

Camera frames are processed locally in the visitor's browser. They are not uploaded or stored by this project.
